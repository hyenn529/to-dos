# 하루 (가칭) — 둘이 같이 쓰는 to-do

할 일만 보면 되는 to-do 서비스. 월간 달력은 어느 화면에서도 사라지지 않지만,
일정을 적는 곳이 아니라 **지금 어디쯤 와 있는지 보는 지도**로만 쓴다.
혜인과 민우가 **같은 공간을 함께 쓰되, 체크는 각자 자기 것만** 한다.
웹과 앱(iOS·Android) 모두 대상.

- 시간 개념 없음 — 시각도, 아침·낮·저녁 같은 구간도 묻지 않는다
- **혜인 · 민우 · 업무** 세 갈래 (순서는 보는 사람 기준으로 고정)
- 하루 · 이번 주 · 언젠가 세 가지 보기
- 재촉하지 않는다 — 독촉 알림도, 콕 찌르기도, 스트릭도 없다

## 세 갈래

| 갈래 | 색 | 성격 |
|------|-----|------|
| 혜인 | 라일락 `#A281EE` | 혜인의 개인 일정 — 혜인만 체크 가능 |
| 민우 | 스카이 `#3E9DE8` | 민우의 개인 일정 — 민우만 체크 가능 |
| 업무 | 버밀리언 `#F5503C` | 둘 다 사용 · 기본은 `내 것만` 보기 |

사람 둘은 이웃한 시원한 색으로 묶고 업무만 색상환 반대편 빨강으로 뺐다.
일이 끼어든 날이 달력에서 즉시 튄다. 경고에 색을 쓰지 않으므로 빨강이 비어 있었다.

## 공유 규칙 셋

1. **체크는 자기 것만** — 상대 갈래 항목은 체크박스 대신 점으로 보인다
2. **같이 하는 일은 한 번만** — `같이` 배지가 붙으면 누가 체크해도 양쪽에서 완료
3. **이름은 보는 사람 기준** — 민우가 열면 왼쪽 칸이 민우가 된다

### 설계 이력

- **v0.6** (현재) — 업무를 버밀리언으로 교체, 둘이 같이 쓰는 공유 구조 도입
- **v0.5** — 개인 → 혜인, 민우 갈래 추가. 2단 → 3단
- **v0.4** — 팔레트를 하늘색·연보라로 교체
- **v0.3** — `아침·낮·저녁` 구간까지 제거해 시간 개념 완전 삭제
- **v0.2** — 시간 격자·일정 블록 제거. to-do 중심 + 달력 상주 구조로 전면 재설계
- **v0.1** — 일반적인 캘린더 앱 구조. *시간 단위 관리처럼 느껴져 폐기*
