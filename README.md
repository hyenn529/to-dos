# 겹 (가칭) — 개인·업무 일정 관리

하나의 시간축 위에 **개인**과 **업무** 두 개의 레인을 얹어 관리하는 일정 / 할 일 서비스.
웹과 앱(iOS·Android) 모두를 대상으로 한다.

- 월간 캘린더 · 주간 일정 · 하루 단위 to-do
- 모든 뷰에서 개인 / 업무 구분이 일관되게 유지됨
