# 하루 (가칭) — 캘린더가 늘 곁에 있는 to-do

할 일만 보면 되는 to-do 서비스. 월간 달력은 어느 화면에서도 사라지지 않지만,
일정을 적는 곳이 아니라 **지금 어디쯤 와 있는지 보는 지도**로만 쓴다.
웹과 앱(iOS·Android) 모두 대상.

- 시간 개념 없음 — 시각도, 아침·낮·저녁 같은 구간도 묻지 않는다
- 개인 · 업무 두 갈래로 나눠 관리
- 하루 · 이번 주 · 언젠가 세 가지 보기
- 매일 열어도 질리지 않도록 민트 바탕에 제이드·탠저린 두 색만

## 현재 상태

**화면 설계 단계.** 구현 코드는 아직 없다.

시안은 브라우저에서 바로 열어 볼 수 있다. 라이트·다크 모드 모두 대응.

### 설계 이력

- **v0.3** (현재) — `아침·낮·저녁` 구간까지 제거해 시간 개념 완전 삭제. 팔레트를 민트·제이드·탠저린으로 교체
- **v0.2** — 시간 격자·일정 블록 제거. to-do 중심 + 달력 상주 구조로 전면 재설계
- **v0.1** — 일반적인 캘린더 앱 구조(주간 시간표 + 일정 블록). *시간 단위 관리처럼 느껴져 폐기*
