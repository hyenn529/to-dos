# 하루 (가칭) — 캘린더가 늘 곁에 있는 to-do

할 일만 보면 되는 to-do 서비스. 월간 달력은 어느 화면에서도 사라지지 않지만,
일정을 적는 곳이 아니라 **지금 어디쯤 와 있는지 보는 지도**로만 쓴다.
웹과 앱(iOS·Android) 모두 대상.

- 시간 개념 없음 — 시각도, 아침·낮·저녁 같은 구간도 묻지 않는다
- **혜인 · 민우 · 업무** 세 갈래로 나눠 관리 (순서는 어디서나 고정)
- 하루 · 이번 주 · 언젠가 세 가지 보기
- 매일 열어도 질리지 않도록 하늘색 바탕에 라일락 · 스카이 · 마리골드

## 세 갈래

| 갈래 | 색 | 성격 |
|------|-----|------|
| 혜인 | 라일락 | 내 개인 일정 |
| 민우 | 스카이 | 남자친구 일정 — 내가 하는 일이 아니라 **알고 있어야 하는 일** |
| 업무 | 마리골드 | 회사 일 |

민우 갈래는 완료를 세지 않는다. 사람 둘은 시원한 색으로 묶고 업무만 따뜻한 색으로
떼어내, "내 삶 / 회사" 경계가 색 온도로 읽히게 했다.

### 설계 이력

- **v0.5** (현재) — 개인 → 혜인, 민우 갈래 추가(스카이 승계), 업무는 마리골드로. 2단 → 3단
- **v0.4** — 팔레트를 하늘색·연보라로 교체
- **v0.3** — `아침·낮·저녁` 구간까지 제거해 시간 개념 완전 삭제
- **v0.2** — 시간 격자·일정 블록 제거. to-do 중심 + 달력 상주 구조로 전면 재설계
- **v0.1** — 일반적인 캘린더 앱 구조(주간 시간표 + 일정 블록). *시간 단위 관리처럼 느껴져 폐기*
