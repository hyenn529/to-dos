# 하루(가칭) — 화면 설계서 v0.5

캘린더가 늘 곁에 있는 세 갈래 to-do 서비스. 웹과 앱 모두 지원.
**논의용 초안이며, 구현 코드는 아직 없습니다.**

시각 시안: [`screens.html`](./screens.html)

---

## 0. 세 갈래

| 갈래 | 색 | 성격 |
|------|-----|------|
| **혜인** | 라일락 | 내 개인 일정. 건강·가족·취미·집안일. 기본으로 열리는 갈래 |
| **민우** | 스카이 | 남자친구의 일정. **내가 하는 일이 아니라 알고 있어야 하는 일** |
| **업무** | 마리골드 | 회사 일 |

**민우 갈래는 성격이 다르다.** 완료를 세지 않는다 — 하루가 끝나고 "남았다"고
집계되지 않으므로 개수도 `2 남음`이 아니라 `1 건`으로 표시한다.
출장처럼 여러 날에 걸친 항목은 기간으로 표시하고, 미리 알아야 하는 것은
당일 이전에도 옅게 노출된다.

> **순서는 어디서나 고정: 혜인 → 민우 → 업무.**
> 왼쪽에서 오른쪽(칼럼), 위에서 아래(달력 막대). 색이 헷갈려도 자리로 구분된다.

## 1. 문제 정의와 방향

- 캘린더 앱의 **시간 격자**는 "몇 시에 무엇을 할지" 정하라고 요구해 부담이 된다
- 하지만 **한 달의 흐름**은 계속 보고 싶다

→ 화면을 `왼쪽 = 달력(읽기용) / 오른쪽 = 할 일(작업용)`로 나눈다.
달력은 일정을 적는 곳이 아니라 **지금 어디쯤 와 있는지 보는 지도**다.

## 2. 설계 원칙

| # | 원칙 | 의미 |
|---|------|------|
| 1 | **시간이 아예 없다** | 시각도, 아침·낮·저녁 같은 구간도 없다. 순서가 신경 쓰이면 목록에서 위로 끌어 올린다 |
| 2 | **달력은 읽는 곳** | 칸 안에 글자를 넣지 않는다. 얇은 막대 세 줄로 그날의 *양*만 표시 |
| 3 | **못 한 건 그냥 넘어간다** | 빨간 "지연" 배지 없음. 어제 남은 항목은 맨 위에 조용히 모아 `오늘로 옮기기 / 나중에` 두 버튼만 |
| 4 | **구분은 색 + 자리** | 세 갈래 순서를 어디서나 고정. 라일락과 스카이가 같은 한색 계열이라 **자리 고정이 특히 중요**하다 |

## 3. 정보 구조

### 웹 — 2단
- **왼쪽 (320px 고정)** — 월간 달력 · 범례 · 갈래별 남은 개수. **어느 화면에서도 그대로**
- **오른쪽** — `하루` / `이번 주` / `언젠가` 세 가지 중 하나

### 앱 — 4탭
`하루` / `이번 주` / `언젠가` / `나`
달력은 탭이 아니라 **상단 고정 영역**이다. 스크롤해도 사라지지 않고, 위로 쓸어올리면 그 주 한 줄로 줄어들 뿐이다.

### 데이터 모델 (초안)

```
Todo {
  id
  lane     : 혜인 | 민우 | 업무      // 최상위 속성
  title                             // 필수 — 이것만 있으면 저장됨
  date?                             // 없으면 "언젠가" 서랍
  endDate?                          // 여러 날 항목 (민우 출장 등)
  order                             // 같은 날 안에서의 순서 (손으로 끌어서 변경)
  countable                         // 민우 갈래는 false — 완료 집계에서 제외
  shared                            // 같이 하는 일 표시 ("같이" 배지)
  done, doneAt?
  note?, tags[]
  subs[]   : { title, done }        // 하위 체크
  repeat?
  carriedFrom?                      // 이월 표시 "어제에서"
}
```

시각(`time`), 시간 구간(`part`), 소요시간(`estimate`), 우선순위(`priority`),
지연(`overdue`) 필드는 **의도적으로 없다.**

## 4. 화면별 사양

### S1. 기본 화면 (웹) — `하루`

**왼쪽 달력 패널**
- 6주 × 7일, 칸 높이 58px, 칸 안은 **날짜 숫자 + 얇은 막대 세 줄**뿐
- 막대 순서 위→아래: 혜인 · 민우 · 업무
- 오늘 = 짙은 채움, 선택한 날 = 얇은 테두리, 일요일·공휴일 = 바이올렛 숫자
- 아래에 범례, 그 아래 갈래별 `n 남음` / 민우는 `n 건` / `언젠가 n`

**오른쪽 본문**
- 상단: 날짜 + `하루 / 이번 주 / 언젠가` 전환 + `＋ 추가`
- 이월 안내: "어제 못 한 일이 2개 있어요" → `오늘로 옮기기` `나중에`
- **혜인 · 민우 · 업무 3단**. 각 헤더에 `n 남음` (퍼센트 아님)
- 완료 항목은 접히고, 배경 없이 취소선 + 흐린 글자로만 남음
- 민우 칸의 여러 날 항목은 옅은 스카이 배경으로 미리 노출

### S2. 이번 주 (웹)

- **달력 패널은 그대로.** 선택한 주가 달력에서 테두리로 표시됨
- 오른쪽만 7개 컬럼으로 — **시간축 없음, 그냥 목록 7개**
- 세 갈래가 한 칸에 섞이므로, **라일락과 스카이가 같이 있는 칸 = 둘 다 시간 되는 날**이 한눈에 보인다
- 컬럼 사이 드래그는 **날짜만** 바꾼다

### S3. 모바일 앱

| 화면 | 구성 |
|------|------|
| 기본 | 상단 고정 달력(한 달) + 아래 목록만 스크롤. 목록은 시간 순이 아니라 **혜인 → 민우 → 업무** 순 |
| 갈래 필터 | `전체 · 혜인 · 민우 · 업무` 칩. 하나만 켜면 그 갈래만 |
| 달력 접기 | 위로 쓸어올리면 그 주 **한 줄**로 축소. 완전히 사라지지 않음 |
| 적기 | FAB → 제목만 입력. 제목에 "민우"가 들어가면 갈래가 미리 잡힘. 날짜 안 골라도 됨 |

## 5. 달력 칸 읽는 법

| 표시 | 뜻 |
|------|-----|
| 막대 길이 8 / 14 / 20px | 1–2개 / 3–4개 / 5개 이상 |
| 첫째 줄 (라일락) | 혜인 |
| 둘째 줄 (스카이) | 민우 |
| 셋째 줄 (마리골드) | 업무 |
| 회색 막대 | 다 끝냈거나 지나간 날 — **신경 쓸 필요 없음** |
| 라일락 + 스카이가 나란히 | **둘 다 시간이 되는 날** |
| 아무것도 없음 | 비어 있는 날. 채우라는 표시는 뜨지 않음 |

## 6. 압박을 만들지 않기 위한 규칙

| 상황 | 흔한 앱 | 여기서는 |
|------|---------|----------|
| 할 일 적을 때 | 날짜·시각·소요시간·우선순위를 묻는다 | **제목만.** 갈래 하나 누르고 끝 |
| 어제 못 끝냈을 때 | 빨간 "지연"이 쌓인다 | 맨 위 한 줄 + `옮기기 / 나중에` |
| 순서 정하고 싶을 때 | 시:분을 지정하게 한다 | 시간 개념이 **아예 없다.** 끌어 올리면 끝 |
| 민우 일정이 밀렸을 때 | 내 할 일과 똑같이 미완료로 쌓인다 | 민우 갈래는 **완료를 세지 않는다** |
| 언제 할지 모를 때 | 일단 오늘 날짜가 붙는다 | **"언젠가"** 서랍. 알림도 독촉도 없음 |
| 다 못 한 하루의 끝 | 달성률 20% | 퍼센트를 쓰지 않는다. **개수로만** |
| 연속 기록 | 스트릭이 끊기면 불이 꺼진다 | 스트릭 기능 자체를 **넣지 않는다** |

## 7. 디자인 토큰

**색 온도로 나눈다.** 세 색을 균등하게 벌리면 무지개가 된다. 대신 사람 둘(혜인·민우)은
이웃한 시원한 색으로 묶고 업무만 반대편 따뜻한 색에 둬, **"내 삶 / 회사"** 경계가
색 온도로 읽히게 했다.

**같은 색을 두 벌로 쓴다.** 밝은 값은 막대·체크·아이콘 같은 *표시*에,
짙은 `-ink` 값은 *글자*에. 밝은 하늘색을 그대로 글자에 쓰면 흰 배경에서 읽히지 않는다.

| 토큰 | 라이트 | 다크 | 용도 |
|------|--------|------|------|
| `hyein` | `#A281EE` 라일락 | `#B79BF7` | 혜인 — 막대·체크 |
| `hyein-ink` | `#6B3FC4` | `#C9B4FB` | 혜인 — 글자 |
| `minwoo` | `#3E9DE8` 스카이 | `#5FB5F5` | 민우 — 막대·체크 |
| `minwoo-ink` | `#16639F` | `#8CCBFA` | 민우 — 글자 |
| `work` | `#F2A93E` 마리골드 | `#F5BC64` | 업무 — 막대·체크 |
| `work-ink` | `#8F6100` | `#F8D08C` | 업무 — 글자 |
| `ink` | `#1E2A4A` 딥인디고 | `#E6EDFB` | 글자 · 오늘 |
| `paper` | `#E2EDFA` 연한 스카이 | `#0A0F1C` | 바탕 |
| `surface` | `#FFFFFF` | `#141B2E` | 카드 · 본문 면 |
| `faint` | `#A9B4CF` | `#5A6584` | 흐림 · 완료 |

- 달력 패널에는 **스카이 → 라일락 → 흰색**으로 옅게 흐르는 그라데이션
- **경고용 빨강은 팔레트에 없다.**
- **글자**: 한 가지 산세리프, 굵기로만 구분. 고정폭(모노) 숫자 없음. 달력 숫자만 `tabular-nums`
- **형태**: 격자선 대신 옅은 면과 여백. 모서리 10–12px, 막대는 완전히 둥글게
- **접근성**: 갈래 순서 고정 / 대비 4.5:1 이상 / 터치 44px 이상

## 8. 화면이 좁아지면

달력은 어느 크기에서도 화면에서 빠지지 않는다. 형태만 바뀐다.

| 폭 | 달력 | 할 일 |
|----|------|-------|
| ≥1280 | 왼쪽 고정 패널 · 한 달 전체 | 혜인 · 민우 · 업무 3단 |
| 1000–1279 | 왼쪽 고정 · 패널 폭만 축소 | 3단 유지 (카드 폭 축소) |
| 700–999 | 왼쪽 고정 · 한 달 전체 | 혜인·민우 2단 + 업무 아래 전체 폭 |
| <700 | 상단 고정 · 스크롤 시 그 주 한 줄로 축소 | 한 줄 목록 + 갈래 칩 필터 |

## 9. 결정이 필요한 항목

1. **업무 색(마리골드)** — 사람 둘을 시원한 색으로 묶으려고 업무만 따뜻한 색으로 뺐다.
   셋 다 시원한 계열로 가는 것도 가능
2. **민우 갈래에 체크박스가 필요한지** — 지금은 완료를 세지 않는다.
   같이 하는 일(공항 데려다주기 등)만 체크되게 할지
3. **민우 일정을 직접 적는지, 공유받는지** — 공유라면 초대·동기화·수정 권한 화면이
   추가로 필요하다. 지금은 *내가 적는 것* 전제
4. **갈래를 더 늘릴 수 있어야 하는지** — 3개까지는 좌우 3단이 성립. 4개 이상이면
   접히는 목록 구조로 바꿔야 함
5. **알림** — 아침에 한 번 "오늘 3개 있어요" 정도만 둘지, 아예 없앨지

## 10. 설계 이력

| 버전 | 내용 |
|------|------|
| v0.1 | 일반적인 캘린더 앱 구조(주간 시간표 + 일정 블록). *시간 단위 관리처럼 느껴져 폐기* |
| v0.2 | 시간 격자·일정 블록 제거. to-do 중심 + 달력 상주 구조로 전면 재설계 |
| v0.3 | `아침·낮·저녁` 구간까지 제거해 시간 개념 완전 삭제. 팔레트를 민트·제이드·탠저린으로 |
| v0.4 | 팔레트를 하늘색(스카이) · 연보라(라일락)로 교체. 표시용/글자용 두 벌 구조 도입 |
| v0.5 | **개인 → 혜인**으로 이름 변경, **민우 갈래 추가**(스카이 승계), 업무를 마리골드로 이동. 2단 → 3단 |
