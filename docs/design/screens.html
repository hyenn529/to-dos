화면 설계 / v0.1 / 논의용

겹 — 개인과 업무를 겹쳐 보는 일정 관리

하루는 하나인데 할 일은 두 갈래입니다. 캘린더를 두 개 쓰면 충돌이 안 보이고, 하나로 합치면 구분이 사라집니다. 한 개의 시간축 위에 두 개의 레인을 얹는 것이 이 설계의 전부입니다.

웹 · 데스크톱 iOS · Android 개인 레인 업무 레인 월간 · 주간 · 일간
01

설계 원칙 네 가지

이후 모든 화면 결정은 이 네 가지에서 파생됩니다.

Lane

구분은 색 + 위치

개인/업무를 색으로만 나누면 색약·흑백 출력·작은 화면에서 무너집니다. 왼쪽 3px 스트라이프, 좌우 분할, 아이콘 형태까지 이중으로 인코딩합니다.

Two Objects

일정과 할 일은 다르다

일정은 시간을 차지하고, 할 일은 끝나야 합니다. 같은 날짜축에 그리되 표현을 다르게 합니다 — 일정은 블록, 할 일은 체크.

Context

월간에서도 할 일이 보인다

월간 캘린더 오른쪽에 항상 인스펙터가 붙습니다. 달을 보다가 날짜를 누르면 그날의 개인/업무 할 일을 바로 확인하고 추가합니다.

State ≠ Hue

상태는 형태로

지연·마감임박을 빨강으로 칠하면 개인 레인 색과 싸웁니다. 상태는 채운 배지, 굵기, 점선 같은 형태로 표현합니다.

02

정보 구조

웹은 3단(내비 · 본문 · 인스펙터), 앱은 4탭. 데이터 모델은 동일합니다.

Web — 3 column

사이드바 / 본문 / 인스펙터

사이드바 뷰 전환 · 미니 캘린더 · 레인 토글 · 태그
본문 월간 / 주간 / 일간 / 할 일 목록
인스펙터 선택한 날 또는 선택한 항목의 상세

App — 4 tab

오늘 / 캘린더 / 할 일 / 나

오늘 기본 진입 화면. 개인·업무 탭 전환
캘린더 월간 + 바텀시트, 좌우 스와이프로 월 이동
할 일 날짜 없는 항목 · 마감 임박 · 지연
나 레인 설정 · 알림 · 연동 · 통계

데이터 모델 (공통) — Item { id, lane: 개인|업무, kind: 일정|할일,
title, start?, end?, allDay, due?, done, priority, tags[], repeat?, remind[] }
lane 이 최상위 속성이라 어떤 뷰에서도 같은 필터가 그대로 작동합니다.

Typography

본문은 한글 산세리프, 데이터는 모노

시각·날짜·개수·소요시간은 전부 모노스페이스 + tabular-nums. 숫자가 세로로 정렬되고, 본문과 역할이 눈으로 분리됩니다.

Spacing

4px 배수 그리드

월간 셀 86px, 주간 1시간 33px, 카드 라운드 3px. 곡률을 낮게 유지해 밀도 높은 표에서 형태가 흐려지지 않게 합니다.

Accessibility

색 없이도 읽힌다

레인은 색 + 스트라이프 + 위치로 삼중 표시. 본문 대비 4.5:1 이상, 터치 타깃 44px, 키보드 포커스 링 상시 노출.

05

06

결정이 필요한 것들

답에 따라 화면이 실제로 달라지는 항목만 골랐습니다.

  1. 레인은 2개 고정인가, 늘릴 수 있어야 하나? 개인·업무 2개로 고정하면 좌우 분할이 성립합니다. 3개 이상(예: 사이드 프로젝트)이 필요하면 분할 대신 그룹 목록으로 바꿔야 합니다.
  2. 업무 캘린더를 외부와 연동하나요? Google Calendar / Outlook 연동이 있으면 "읽기 전용 외부 일정" 표현 (빗금 패턴 블록)과 충돌 경고 UI가 추가로 필요합니다.
  3. 혼자 쓰나요, 팀과 공유하나요? 공유가 있으면 담당자 아바타·공유 배지·권한 설정이 카드와 셀에 들어가야 합니다. 지금 시안은 1인 사용 전제입니다.
  4. 주 시작 요일과 근무 시간대 시안은 월간=일요일 시작, 주간=월요일 시작, 시간축 08–20시로 그렸습니다. 설정으로 뺄지 고정할지 정해야 합니다.
  5. 미배치 할 일 → 시간표 드래그, 꼭 필요한가? 가장 만들 맛 나는 기능이지만 구현 비용이 가장 큽니다. 1차에서 뺄 수 있고, 빼면 주간 뷰가 훨씬 단순해집니다.
  6. 다음 단계 우선순위 ① 화면 확정 → 클릭 가능한 프로토타입, ② 바로 프론트엔드 골격 구현, ③ 데이터 모델·API 설계 먼저. 어디부터 갈지 정해 주세요.
